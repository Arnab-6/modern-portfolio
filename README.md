# 🌲 Arnab Saha — Builder & Engineer Portfolio

A static portfolio website engineered with the visual identity and aesthetic of **Hack The Nest** (`hackthenest.tech`): twilight sky gradients, warm sunset hues, earthy soil tones, **Space Grotesk** headings, **Manrope** typography, and **Caveat** handwritten accents.

---

## 🎨 Visual Identity & Design System

- **Twilight-to-Sunset Atmosphere**: Multi-stop gradient backdrop (`#2b2140` twilight sky to `#f6a25c` sunset horizon and `#130911` deep soil bedrock) with stars and mountain silhouettes.
- **Typography**:
  - `Space Grotesk`: Bold, technical, modern hacker headings.
  - `Manrope`: Readable, clean body text.
  - `Caveat`: Playful handwritten annotations, field notes, and arrows.
  - `JetBrains Mono`: Monospace terminal code blocks.
- **Sketch Paper Notebook Card**: Hand-drawn paper texture with folded edge and tape accent for the engineering story.
- **Filterable Track Cards**: Styled with Hack The Nest depot/track badge accents (AI & Systems, SaaS, E-Commerce, Multiplayer CRDT).
- **Interactive Case Study Modals**: In-depth architecture diagrams, metrics, challenges, and solutions.
- **FAQ Accordion**: Styled after the Hack The Nest interactive FAQ accordion.
- **Interactive Terminal & Live Code Card**: Terminal window featuring typed configuration and core principles.
- **Functional Contact Form & Copy Email**: Real-time form validation and copy-to-clipboard toast notification.

## 🚀 How to Run & Preview

### Option 1: Direct File Open
Double-click [`index.html`](index.html) or open it in your browser.

### Option 2: Local HTTP Server
Run from this directory:
```bash
python3 -m http.server 3000
```
Then navigate to: [http://localhost:3000](http://localhost:3000).
